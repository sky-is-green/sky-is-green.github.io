# sky-is-green.github.io

Personal portfolio, live at **https://sky-is-green.github.io/**.

A retro-terminal one-pager in phosphor green, built around low-bit systems:
the things I take apart to understand, and rebuild smaller.

## Structure

- `index.html` / `styles.css` / `app.js`: the site (zero build step, zero
  runtime dependencies)
- `data/profile.json`: name, tagline, about, skills, links, and the contact
  address (email, subject and the copy)
- `data/projects.json`: the curated work list. Policy: **public repos only**,
  and only work with a large personal contribution; fork/engine work appears as
  *contributions*, labeled with the personal commit count
- `data/open.json`: open projects, what is not finished. Same card shape as
  the work list, plus a `status`, which is the badge on the card's head row;
  the cards slide rather than roll
- `assets/qr/hero-qr.png`: the hero, a pixel-art cat that is a fully scannable
  QR code pointing at this page, generated by
  [PixelQR](https://github.com/sky-is-green/pixelqr). `avatar-1024.png` /
  `avatar-512.png` are the same code squared for use as a profile avatar, where
  the extra margin is what a circular crop needs. `make-hero-qr.js` +
  `make-hero-qr.py` regenerate the hero render: identical modules, but drawn
  full-bleed, with a 4-module quiet zone and nothing else, so the code fills the
  frame it is shown in (80% of the file, against 58% for the avatar). The
  scripts `require` `../pixelqr/core.js` (or take a path to any copy), and the
  hero pins the mask (7) so the hero and the avatars always carry one code.
  PixelQR itself can now draw the round profile picture directly: the QR
  inscribed in a circle, so all three finder patterns survive the crop.
- `assets/fonts/`: self-hosted VT323 + Silkscreen (SIL OFL 1.1)
- `planning/`: the original scope doc and the avatar proof-of-concept work
- `.nojekyll`: so Pages serves the folder exactly as-is

## Editing

Content lives entirely in `data/profile.json`, `data/projects.json` and
`data/open.json`; everything else is presentation.

Navigation is a numbered DOS-style menu: click the items or press `1`–`4`
(about / work / open projects / contact). The work section is a Pip-Boy-style
**3D drum**: the nine projects sit on a virtual cylinder (every project gets
`360°/N` of it, so it closes without a seam) and scrolling (wheel, touch swipe,
mouse drag) rotates it; cards curve and recede like a real tumbler. `▲` `▼`,
arrow keys, and the numbered ticks jump; tag chips rewind the drum to a
filtered set; `crt` toggles the scanlines.

The contact section shows a Firefox Relay alias rather than a real inbox: mail
sent to `qbz7imbtw@mozmail.com` is forwarded by Relay to the real address, so
the inbox itself is in no file in this repo, and only the alias is published. The
alias is created and managed at relay.firefox.com; nothing on the page needs
it to be anything but a `mailto:`.

Open projects uses the same cards in the same monitor with the motion swapped
for a slide: a scroll-snap track, one card centred at a time, a sliver of each
neighbour left showing at the edges. Swipe, drag or let trackpad gestures move
it; `[ ◀ ]` `[ ▶ ]`, the left/right arrows and the numbered ticks step a card
at a time. The card that is centred wakes and writes itself in; the ones either
side hold their standby plates, as the cards off the front of the drum do.

## One-time setup

GitHub Pages: **Settings → Pages → Source: Deploy from a branch → `main` /
`/ (root)`**. Then https://sky-is-green.github.io/ serves this repo directly.
